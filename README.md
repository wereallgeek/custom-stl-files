# custom-stl-files
Custom STL files used in geek projects.

Here is to store STL files I had to alter when printing.


# C64 casebadge 1mm.stl
 loosely based on the C64Badge.stl file from the [Commodore 64 2021](https://www.thingiverse.com/thing:4806300/files) project by [kevinthefixer](https://www.thingiverse.com/kevinthefixer/designs)

 Thanks kevinthefixer for this project. The original case badge was meant for his C64 inspired project so I had to resize it to the _usual_ 110mm x 11mm used for C64 breadbin case badges. I also changed thickness so that the base is 1mm thick, required for printing.
